# Bank Tab Sorter

Sorts your bank tab items by Grand Exchange value (highest to lowest).
- Visually rearranges items in your bank tab by GE value
- Items remain fully interactive - you can still withdraw/deposit normally
- Your actual bank organization is never changed

## How to use

1. Open your bank
2. Right-click the bank settings button (gear icon)
3. Select "Sort items by GE value"
4. To undo: Right-click settings again and choose "Restore original order"

## Notes

- Works on any bank tab including "View all items"
- Automatically updates when you withdraw/deposit items
- Resets when switching between tabs
